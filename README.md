## 怎么用

1. 把整个仓库下载下来（`Code` → `Download ZIP`，或 `git clone`），**保持目录结构**。
2. 双击 **`启动Nec破解版.bat`**。
3. 窗口里出现 `[OK] 破解完成` 就成功了——客户端会自动登录、进入主界面，**不需要卡密**。
4. 第一次用某个游戏前，先双击 **`安装模型.bat`**，再点游戏里的「开始推理」。

启动过程中那个黑色命令行窗口**不要关**；看到 `[OK]` 之后可以关掉（不影响已经启动的程序），也可以直接最小化。

## 目录说明

| 文件 / 目录 | 作用 |
| --- | --- |
| `启动Nec破解版.bat` | 一键启动入口（双击这个） |
| `launch.py` / `patch.py` | 启动器与卡密绕过补丁的实现 |
| `verify.py` | 自检脚本：`py -3 verify.py --quick`，退出码 0 = 通过 |
| `安装模型.bat` | 把随包模型装到 `%USERPROFILE%\Documents\` |
| `准备模型.py` | 缺模型时自动下载（SHA-256 校验） |
| `模型缓存\` | 7 款游戏的 ONNX 模型 |
| `运行依赖\` | 自带的 Python 3.14 运行环境 |
| `Nec\` | 客户端本体（程序实际跑的就是这里） |
| `使用说明.txt` | 同内容的纯文本版说明 |

## 说明与限制

- **免卡密**：启动器在客户端弹出卡密窗后自动完成登录，卡密框留空也行。
- **只改内存不改磁盘**：补丁写在运行中的进程里，程序退出即失效；下次重新双击入口即可。
- **自带运行环境**：目标机器**不需要安装 Python**（包内已带）。
- **首次「开始推理」会闪退一次**是客户端自己下模型的毛病：它第一次要把模型下载到
  `%USERPROFILE%\Documents\<编号>.txt`，在那一步会崩一次。先跑 `安装模型.bat` 把模型装好就不会遇到；
  如果换新游戏又遇到，跑一次 `准备模型.py` 补下即可。
- **版本绑定**：只对当前这份客户端（`Nec\AudioBuffer.dll`）有效。程序更新换了 DLL 后补丁会失效——
  脚本检测到字节不符会**直接拒绝写入并报错**，不会把程序打坏。
- 仅用于技术研究与学习交流。
