Nec 破解版 —— 使用说明
============================================================

一键使用
------------------------------------------------------------
双击  启动Nec破解版.bat

它会自动完成：启动客户端 -> 写入卡密绕过补丁 -> 填一张任意卡密 ->
点登录 -> 关掉结果提示框 -> 进入主界面（客户端保持运行，正常使用）。

运行环境已随包附带（运行依赖\Python\，Python 3.14，脚本只用标准库）：
目标机器上**不需要安装 Python**，启动器会自动调用包内解释器；
万一包内解释器缺失，才会回退到系统的 py -3（那种情况才需要自己装 Python）。

关于启动时那个黑色命令行窗口（能不能关）：
  · 破解过程中**不要关**——关早了补丁可能没打上；
  · 看到 [OK] /「破解完成」之后**可以关掉**，关掉不影响已经启动的程序，
    也可以直接最小化放着不管；
  · 如果显示 [FAIL]，先别关，把窗口里的报错截图发到群里。

破解交流群：777410175   （更新、答疑、失效反馈都在群里）


文件夹里有什么
------------------------------------------------------------
Nec（Wb）.exe        原版主程序（RAR 自解压安装包）。想重装/修复时双击它，
                     SFX 会把客户端装到 C:\Program Files\Nec。
                     注意：它启动时会强杀 kwmusic.exe / KwService.exe。
Nec\                 已经装好的客户端本体（真正的程序在这里），
                     启动器就是跑这个目录下的 kwmusic.exe。
启动Nec破解版.bat    破解入口，双击即用。
launch.py            启动器实现（启动 + 打补丁 + 自动过卡密窗）。
patch.py             补丁实现（卡密校验绕过，只写内存不改磁盘）。
verify.py            验证脚本（py -3 verify.py --quick / --full，退出码 0 = 通过）。
准备模型.py          下载各游戏的 ONNX 模型到本包的「模型缓存」目录（SHA-256 校验）。
安装模型.bat         把「模型缓存」里的模型复制到 %USERPROFILE%\Documents（客户端读这里）。
运行依赖\Python\      自带的 Python 3.14 运行环境（脚本只用标准库，无需另装 Python）。
模型缓存\            7 个游戏的模型文件（1.txt / 2.txt / 3.txt / 13.txt / 6.txt / 21.txt / 5.txt），已备好。
使用说明.txt          本文件。


模型（重要，必看）
------------------------------------------------------------
点「开始推理」时，客户端会把对应游戏的 YOLO 模型下载到
    %USERPROFILE%\Documents\<编号>.txt      （PUBG=1.txt，COD=2.txt，OW=3.txt，
                                             R6=13.txt，TheFinals=6.txt，Rust=21.txt，CSGO=5.txt）
第一次点、而缓存还不存在时，它要现下载——实测会在「正在获取模型」这一步闪退一次
（模型本身没问题，是它下载/加载交界处的毛病）。
所以：**先用「安装模型.bat」把模型装好，再点「开始推理」**，就不会闪退。
本包已经把这 7 个模型都下好放进了「模型缓存」，直接双击 安装模型.bat 即可。
   · 想重新下/补下模型：py -3 准备模型.py          （全部）
                          py -3 准备模型.py PUBG COD（指定游戏）
                          py -3 准备模型.py --list   （看缓存状态）
   · 装模型时如果正在推理，1.txt 可能提示"拒绝访问"（文件被占用），关掉程序再装一次就行。
   · 已经装好且校验通过的话，装模型.bat 会显示 [OK] 7 个。


自己验证
------------------------------------------------------------
py -3 verify.py --quick     快速验收（启动->打补丁->进主界面->清理），退出码 0 = 通过
py -3 verify.py --full      完整验收，额外把判据原始值写进 evidence\verify_full.json 并截图
py -3 patch.py show --pid N 查看某进程内补丁当前状态
py -3 patch.py restore --pid N  把原始字节写回（还原）
py -3 准备模型.py --list    检查模型缓存是否齐全（SHA-256 校验）


原理（一句话）
------------------------------------------------------------
卡密校验在 Nec\AudioBuffer.dll（Themida 加壳，磁盘文件是加密的，改盘没用），
运行期才在内存里解密。启动器等卡密窗出现后，在 KwService.exe 进程内定位
AudioBuffer.dll，改写两处字节：
  RVA 0x9F24E6   jne 失败分支 -> 无条件跳成功分支
  RVA 0x1573     卡密长度门（32~40 字符）-> 解除
于是程序自己判定登录成功，弹出「登陆成功!」并把主界面交出来。


必须知道的限制
------------------------------------------------------------
* 补丁只在内存：进程退出即失效。每次都要用 启动Nec破解版.bat 启动，
  直接双击 Nec\kwmusic.exe 不会带补丁。
* 版本绑定：只对当前这份 Nec\AudioBuffer.dll 有效。
  程序更新/换了 DLL 后补丁会失效——patch.py 检测到字节不符会直接报错拒写，
  不会盲打坏程序。
* 只改内存不改磁盘：不想用了，关掉程序就行；磁盘文件一直是原样
  （AudioBuffer.dll 的 sha256：66b5fef9fc239e49cd7bc703b235245d55a16cfef545de7a68b8b301f5cd29b8）。
* 过程中若浏览器/音乐窗弹出来是正常的，那是客户端的伪装界面。
* 成功框里显示的「账号过期时间:1970-01-01」是本地到期字段为 0 的表现，
  不影响进入主界面使用。
